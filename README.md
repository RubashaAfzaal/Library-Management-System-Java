# 📚 Library Management System (Java Swing & OOP)

A desktop application designed for managing library administrative operations, staff logging, and student book transactions. Built using Object-Oriented Programming (OOP) principles and Java Swing for interactive graphical interfaces.

## ✨ Features
* **Role-Based Portals:** Separate modules and authentication flow for Admin, Librarian, and Student roles.
* **Book & Staff Management:** Options to add, view, and search catalog entries dynamically.
* **Transaction Engine:** Real-time book issuing, returns, and history tracking.
* **Data Persistence:** Integrated text file I/O handling for storing persistent records.

## 🛠️ Tech Stack
* **Language:** Java (JDK 8+)
* **UI Framework:** Java Swing (`javax.swing`)
* **Core Concepts:** Object-Oriented Programming, File I/O, Data Structures

## 🚀 How to Run
1. Download or clone the repository.
2. Open terminal/command prompt in the project folder.
3. Compile all source files:
```bash
javac *.java
```
4. Run the main launcher:
```bash
`java MainGUI`
 ```
